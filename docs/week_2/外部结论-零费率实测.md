## 二、可以直接引用的结论

### ★ 最重要:费率归零之后,依然没有机会

这条直接堵死了我文档里那个未验证的逃生口 ——
我之前写「25 bps 是 LI.FI 服务费,可议价,谈到 5 bps 结论就翻转」。
**它把费率扣到 0 重算了一遍:**

```
口径二 · 零费率(逐腿从 feeCosts 读真实值扣回,非常量假设)

资产      min      中位     max     正收益     ≥+10 bps
WETH     −7.3    −1.2    +7.2    33/120        0
wstETH   −7.7    −1.7    +4.9    25/120        0
USDT     −0.1    +6.4    +9.4   109/120        0
LINK    −81.4   −47.6    +8.0     1/120        0
```

**即使费率为零,120 轮里一轮都没到 +10 bps。**

作者的解释很到位:WETH / wstETH 在零线附近微幅摆动,
**符合无套利区间理论 —— 价差被"搬平成本"夹住**。

> 唯一持续为正的是 USDT 的 base 买 → arbitrum 卖,中位 +6.4 bps、109/120 轮为正,
> 方向稳定得像个真实的微小基差(Base 侧 USDT 流动性偏浅),
> **但量级不足以覆盖 gas 与再平衡成本。**

**对我的意义**:结论从「因为 LI.FI 抽 25 bps 所以不成立」升级为
**「即使不抽也不成立」**。我的分口径限定词依然正确且必要,但那个逃生口现在有数据了。

### 标的选择的第一准则是成本地板,不是波动率

作者本来的直觉是「换成流动性更薄、波动更大的资产会更有机会」,
逐个实测 24 个候选的**同链往返成本地板**之后,**结论与直觉相反**:

```
UNI  @ Optimism   −562.9    需 5.6% 错位才回本
COMP @ Base       −427.8    不可用
AAVE @ Optimism   −198.1    不可用
LDO  @ Arbitrum   −168.3    不可用
CRV  @ Base       −102.6    不可用
LINK              −47.6     第一版标的,据此剔除
WBTC @ Arbitrum    −1.8     可用
weETH @ Base       −0.2     全部候选中最紧
```

> **标的选择的第一准则是成本地板,不是波动率,也不是"小众程度"。**

**对我的意义 —— 这条是给我主线的警告。** 我的差异化方向是
**长尾链清算**,而"长尾"通常意味着薄,薄意味着成本地板可能吃掉全部机会。

我的清算主业有个不同点(清算奖励是协议给的固定折扣,不完全靠价差),
但**抵押物变现那一腿完全适用** —— 变现滑点就是我的成本地板。
所以选清算标的时,第一步应该是测抵押物的变现成本地板,不是看清算奖励有多高。

## 三、值得借鉴的方法(我可以自己实现)

### 1. 同链买卖往返 —— 一个能定位坏数据源的不变量

**我现在的不变量检查**:`toAmountMin > toAmount`(单腿内部矛盾)
**它的不变量检查**:同一条链上买入后立刻卖出,**必然亏掉双边 DEX 成本,任何正值都说明报价体系自相矛盾**

```
证据一:同链买卖往返(零费率口径,中位 bps)
资产      Arbitrum  Optimism   Base
WETH       −1.7      −7.2    +36.3   ← Base 一列全线倒挂
wstETH     −3.3      −8.5    +29.3
USDT       +0.6      −0.2    +26.8
```

**在这张表里正值意味着报价体系坏了,不是赚钱。**

它比我的检查强在:**能定位到是哪个源坏的**。按(买腿路由 × 卖腿路由)拆解:

```
fly → fly              WETH    +44.5   ← 越过零线
kyberswap → fly        WETH    +35.5   ← 牵涉 fly
okx → okx              wstETH   +0.4   ← 正常形态
kyberswap → okx        USDT     −0.1   ← 正常形态
```

**凡是牵涉 `fly` 的配对全部越过零线;不牵涉它的全部落在 0 附近或为负。**

结论:`fly`(Fly.trade / Magpie)的 `toAmount` **系统性高估**。

### 2. 最狠的推论:虚报产出的报价源会赢得路由竞争

> 当某个源虚报产出,它就会**赢得路由竞争**并出现在结果里。

这是个**选择效应** —— `/quote` 的「最优路由」会系统性偏向最乐观的报价源。
**数据最差的那个反而最容易被选中。**

**对我的意义**:我查过自己的 `watch/*.jsonl`,路由是
`eco / stargateV2 / relaydepository / layerswap / mayanFastMCTP / mayan / polymerStandard / across`,
**`fly` 没出现过**。但机制对我一样适用 —— 我那条跨资产往返路径
**60% 的观测伴随 `toAmountMin > toAmount`**,是同类信号,只是我还没做同链往返去定位是哪个源。

### 3. 量 edge 必须并发取腿

> 一轮内全部腿并发发出,组内跨度 **9–31 ms**。
> 参考实现的串行采集约 **14 秒**,噪声与信号同量级,**结论不可用**。

**这一条对我目前不致命,因为我量的东西不一样:**

| | 量什么 | 串行行不行 |
|---|---|---|
| 它 | edge = 两个大数相减出的小数 | ❌ 几秒漂移就淹没信号 |
| 我 | 闭环成本 ≈ 60 bps,标准差 3 bps | ✅ 影响有限 |

**但一旦从「量成本」转到「量 edge」,并发就是必须的。** 这是 Week 3 真要找机会时绕不过的一步。

### 4. 隔离而不是静默剔除

作者的处置:

1. `analysis.py` 加入 `QUARANTINED_TOOLS` 隔离名单,**隔离条数在报告中显式打印,不做静默剔除**
2. 新增回归测试锁住该行为
3. 证据写进笔记

**「显式打印隔离数」这个做法值得抄。** 我的 `wick_scan.py` 剔除脏数据时也打印了剔除条数,方向一致 ——
静默剔除会让你以为数据本来就干净。

## 四、不能外推的部分(以后别误用)

作者自己在 §6 明确列了局限,照抄下来:

> - **最大局限**:全部结论**基于报价而非成交**。fly 事件恰恰说明报价可能失真,
>   报价与成交的偏差分布**尚未测量**。
> - **样本局限**:两小时、**单一平静时段**、三条 L2、$1,000 名义规模。
>   结论不外推到其他行情、链或规模。
> - **成本内含**:edge 已含 DEX 手续费、价格冲击与 LI.FI 协议费;
>   **未含 gas**(同链约 0.6 bps @ $1,000)。

### 我自己要补的一条局限:120 轮不是 120 个独立观测

PDF 报「0/120 正收益」,读起来像 120 次独立试验。但采样是**每分钟一轮、
连续 2 小时** —— 跨链价差在 1 分钟尺度上高度自相关,平静时段里连续两分钟
的价差几乎必然相似。**有效样本量远小于 120。**

对比:

```
它:  120 轮 / 2 小时     每分钟一轮    跨 0 个昼夜
我:   98 轮 / 48.5 小时  每半小时一轮  跨 2 个昼夜
```

**高频采样短窗口 ≠ 大样本。** 这是我刚学到的「n=3 → n=98」那条教训的另一面:
上次是样本太少,这次是**样本不独立**。

> 作者自己也指向了这点(§3):「这条曲线决定了本轮结论的适用范围:
> 我们证明的是**平静行情下**无机会」,并且下一轮要统计的
> 「不是中位数,而是**事件的发生频率与持续时长**」。他已经开了 24 小时的 v2
> (`run_id: 24h_v2_20260806T033308Z`)。

**所以这是个标注了适用范围的诚实结论,不是过度外推。** 引用时把范围一起带上。
