# 教学:什么是「针」和「接针」

> 起因:共学群 #06 话题提到「接针」策略　|　工具:[`wick_scan.py`](../../wick_scan.py)
> 数据源:The Graph　|　日期:2026-08-06

这篇假设你完全没接触过 K 线和挂单交易。先讲概念,再讲怎么用数据验它。

---

## 1. 什么是「针」

### 1.1 先看一根 K 线有几个价

链上每个池子,每小时都会记录四个价格:

| 名字 | 意思 |
|---|---|
| **open** 开盘 | 这一小时**开始**时的价格 |
| **high** 最高 | 这一小时里**触及过的最高**价 |
| **low** 最低 | 这一小时里**触及过的最低**价 |
| **close** 收盘 | 这一小时**结束**时的价格 |

画成图就是一根蜡烛:开盘到收盘画成一个方块(叫**实体**),最高和最低各拉一条线出去(叫**影线**)。

### 1.2 「针」= 特别长的下影线

```
   开盘 0.535 ─┐
               │  实体(开盘到收盘,变化很小)
   收盘 0.536 ─┘
               │
               │   ← 这段就是「下影线」
               │
   最低 0.531 ─┘
```

**「针」就是下影线特别长的情况** —— 价格在这一小时里一度砸得很深,但收盘时又回到了原来的位置。画在图上像一根细长的针扎下去。

关键在于**扎下去又弹回来**。如果是一路跌下去收在最低点,那不叫针,那叫阴跌。

> 所以脚本里判断针的公式是:
> ```
> 针深 = (min(开盘, 收盘) − 最低价) / min(开盘, 收盘)
> ```
> 用 `min(开盘, 收盘)`(实体下沿)而不是开盘价,就是为了排除阴跌 ——
> 我们要的是"扎下去又回来",不是"一路跌"。

### 1.3 针为什么会出现

某一刻有人**急着卖**:爆仓被强制平仓、恐慌砸盘、机器人参数写错、有人要跑路。

而那一刻**池子里没那么多钱接**。深度不够,一笔大单就把价格推出去很远。

> 这就是你 Week 1 学的「深度决定价格冲击」—— **针是价格冲击的极端形态**。

### 1.4 针为什么会弹回来

因为价格跌那么深**不是因为这个币变差了**,只是那一秒没人接盘。

砸完之后,别人发现"这价格太便宜了",就会来买,价格回去。

**这个"弹回来"才是接针能赚钱的全部前提** —— 如果不弹回来,你就是接了个正在归零的盘。

## 2. 什么是「接针」

**提前**在那个深坑的位置挂好买单,等着它扎下来的时候成交。

```
现价              1.00 USDT

                            ← 你在这里挂买单:0.60

某一刻突然砸到 0.58   →   你的单成交了,0.60 买到
十分钟后弹回 0.95     →   赚 58%
```

**核心是:你不预测它会跌,你只是把单子放在那里等。**

大部分时候一辈子不成交,偶尔成交一次就是暴利。

群里 feiye2165 说的「**小资金遍撒网,一个 500 撒完也是十几二十万**」就是这个 ——
你不知道哪个币会扎针,所以在几百个币上各挂一点。

### 2.1 链上怎么挂这个单

AMM(自动做市商)里没有传统的"限价单"。但是 ——

**单边存入的集中流动性 = 一张限价单。**

你在 0.58~0.60 这个区间只存 USDT,因为区间在现价下方,此刻它是 100% 的 USDT。
只有价格跌进来,才会有人拿币换走你的 USDT。**这就是一张限价买单。**

> 这一点在你验证[收费站套利法](收费站套利法-验证.md)时已经讲过,是同一个机制。

### 2.2 AMM 比交易所有个好处

**交易所挂单可能被"跳过"** —— 价格瞬间从 0.65 跳到 0.55,中间没有成交,你 0.60 的单可能没成交。

**AMM 不会。** AMM 的价格是沿着数学曲线**连续移动**的,想从 0.65 到 0.55,
就必须一路"走"过 0.60,而走过的时候就必然吃掉你的单。

> 所以用"这一小时的最低价跌破了我的挂单价"来判断"会不会成交",在 AMM 上是可靠的。
> 这也是为什么这个策略能用历史数据回测 —— 成交与否是确定的,不用猜。

## 3. 接针 vs 收费站:近亲,但经济学相反

你刚验证过的收费站,链上操作**和接针是同一种**:单边 USDT 挂在现价下方。
区别在**放哪儿、赚什么**:

| | 收费站 | 接针 |
|---|---|---|
| 区间位置 | **贴近**现价(-1% ~ -5%) | **远离**现价(-20% ~ -50%) |
| 希望发生什么 | 价格反复穿越,来回收费 | **一次**深针 |
| 收入来源 | 手续费 | 买到便宜货 + 价格回弹 |
| **被成交对你** | **坏事** —— 你被逆向选择了 | **好事** —— 这就是目的 |

最后一行是关键差异。收费站里被填单是亏损的开始;接针里被填单才是赚钱的开始。

**但陷阱是同一个:你被谁填的?**

- 被**爆仓/恐慌**填 → 那是"非信息流",价格会回来,你赚
- 被**真实坏消息**填(项目跑路、合约被黑) → 价格不回来了,你接的是归零盘

**能不能区分这两种,就是这个策略的全部。**

## 4. 这个能不能用数据验?需要挂服务器吗

**不用挂服务器,一个脚本就能拉。**

这是个重要区分,之前也遇到过:

| 数据 | 性质 | 怎么拿 |
|---|---|---|
| LI.FI 成本门槛 | **易逝** —— 报价是链下的,不采就永远没了 | 必须挂监控 |
| 链上价格/针 | **可回溯** —— 一直躺在链上 | 随时拉,拉多久之前都行 |

针是历史上真实发生过的链上事件,`poolHourDatas` 里每小时的 `low` 一直都在。

要回答的两个问题:

1. **深针多久出现一次?** → 决定你的钱要空等多久(资金占用成本)
2. **扎完之后回不回来?** → 决定你接的是便宜货还是归零盘

## 5. 手动复现

### 第 1 步:确认 The Graph 能用

```bash
cd ~/MEV-LIFI
python3 lib/graph.py
```

(需要 `.env` 里有 `THE_GRAPH_KEY`,见[收费站验证文档](收费站套利法-验证.md)第 3 节)

### 第 2 步:扫一批池子

```bash
python3 wick_scan.py --chain BNB-V4 --days 30 --top 25 --depth 5,10,20,30
```

参数含义:

| 参数 | 意思 |
|---|---|
| `--chain BNB-V4` | 用 uniswap-v4-bnb 这个数据源(**为什么不是 BNB,见第 7 节**) |
| `--days 30` | 往回看 30 天 |
| `--top 25` | 扫前 25 个池 |
| `--depth 5,10,20,30` | 分别统计针深 ≥5% / 10% / 20% / 30% 的情况 |
| `--recover-hours` | 扎针后多少小时内算"回弹",默认 6 |

### 第 3 步:读输出

```
     针深度      出现次数       覆盖小时         平均多久一次       回弹率        持有中位收益
  ≥5%          42      3,016          72 小时       88%       +17.8%
  ≥10%          36      3,016          84 小时       89%       +22.0%
  ≥20%          14      3,016         215 小时       86%       +44.4%
  ≥30%           8      3,016         377 小时       88%       +75.8%
```

**逐列解释**:

- **出现次数** —— 30 天里所有池子加起来,出现了几根这么深的针
- **覆盖小时** —— 一共分析了多少个"池子·小时"
- **平均多久一次** —— 覆盖小时 ÷ 出现次数。≥30% 的针平均 **377 个池子小时**才出一根
- **回弹率** —— 扎针后 6 小时内,**收盘价**有没有回到扎针前的位置
- **持有中位收益** —— 在针尖买入、6 小时后无脑卖出的收益中位数

两个收益口径必须分清:

```
上限收益   针尖买入 + 窗口内最优收盘价卖出   ← 需要完美择时,做不到
持有到期   针尖买入 + 窗口末尾无脑卖出       ← 不择时,这才是可复现的
```

## 6. 结果长这样,但**先别高兴**

表面上看数字很好:≥30% 的针,88% 会回弹,持有中位收益 +75.8%。

**但这批数据有三个严重问题,足以让结论不成立。**

### 问题 1:样本集中在一个币上

```
quq/USDT     fee0.00%   ≥30%: 4 根
quq/USDT     fee0.01%   ≥30%: 3 根
USDT/FF      fee0.00%   ≥30%: 1 根
其余 5 个池              ≥30%: 0 根
```

**8 根深针里有 7 根来自同一个币 `quq`。** 所谓"88% 回弹率"基本就是在描述
一个币在几天内的表现,不是一个可推广的规律。

### 问题 2:幸存者偏差(最致命)

脚本是按**今天的 TVL / 成交额**取前 25 个池。

**那些已经归零、跑路、被黑的币,今天 TVL 接近 0,根本进不了这个榜单。**

而接针最大的风险恰恰就是接到这类币。所以:

> **这个扫描系统性地把"接针接到归零盘"的情况排除掉了。**
> +75.8% 是一个**被向上偏置的上限**,不是预期收益。

要修正这个偏差,得按**当时**(30 天前)的池子列表来扫,而不是按今天的。
这是下一步该做的事。

### 问题 3:成本一项没算

```
净收益 = 回弹收益
       − gas(建仓 + 撤仓 + 换回稳定币)
       − 资金空等的机会成本      ← 平均 377 个池子小时才出一根针
       − 接到归零盘的那些次       ← 被问题 2 系统性排除了
```

「遍撒网」意味着你的钱**同时**趴在几百个位置上等,绝大部分永远不成交。
那些钱的机会成本,一分都还没扣。

## 7. 我踩的三个坑(比结论更有用)

### 坑 1:回弹率 100% —— 这是数据/判据出问题的信号

第一版跑出来,**每个深度的回弹率都是 100%**。

我当时的判据是:"扎针后 6 小时内,**最高价**有没有回到扎针前位置"。

问题在于 —— **最高价你根本卖不到**。那只是盘中瞬间碰了一下。
而在一个来回震荡的币上,"某小时最高价超过某个位置"几乎必然成立,
所以判据永远为真。

改成用**收盘价**判定之后,回弹率降到 86~89% —— 这才是合理数字。

> **通用规则:任何策略回测算出 100% 成功率,先怀疑判据,别庆祝。**
> 真实世界没有百发百中的东西。100% 通常意味着你的判据里藏了一个恒真条件。

### 坑 2:脏数据伪装成超级机会

第一版还扫出这么一行:

```
针深 100.0%   成交价 7.74897e-07   之后最高 259.083   毛收益 +33,434,577,976%
```

池子价格在 260 左右,某小时的 `low` 却是 `0.0000007`。这不是针,是**坏数据**。

现在加了不变量检查:针深 >90%、或者那一小时成交额 <1000 美元 / 笔数 <3 的,
一律剔除(实测剔掉 4 根)。

> 呼应你的铁律候选:**对上游数据做不变量检查。**
> 这次是第三回了 —— `toAmountMin > toAmount`、subgraph TVL 虚高 3~6 倍、现在这个。

### 坑 3:同一个 schema,不同 subgraph 能力差很远

原本想用 `BNB`(Uniswap V3 BNB)这个数据源,结果:

- `pools(first:5)` ✓ 能查
- `pools(first:25)` ✗ 报 `bad indexers`
- `skip` 分页 ✗ 也失败
- TVL 字段值是 `$36,862,037,375,427,233,997,167,854,618,354,384,896`(3.7×10⁴⁶)—— **坏的**

换成 `BNB-V4`(uniswap-v4-bnb)才正常(TVL $31.6M,合理)。

> 之前学到「验 subgraph 要验目标实体在不在」,这次又加一条:
> **还要验具体查询能不能跑。** schema 有那个字段 ≠ 索引器能给你那个结果。
> `first:5` 能跑 `first:25` 不能跑,这种事只能实测。

## 8. 当前结论

**不成立 —— 但理由是"证据不足",不是"已证伪"。**

和收费站不一样:收费站我们算出了明确的负数(手续费只覆盖 15.6% 的亏损)。
接针这里,数字表面上是正的,但**这个正数不可信**,因为:

1. 7/8 的样本来自一个币
2. 幸存者偏差系统性排除了归零案例
3. 资金空等成本、gas 一项没扣

**要让这个结论变硬,下一步该做的:**

- [ ] 按**历史时点**的池子列表扫,而不是今天的榜单(修幸存者偏差)
- [ ] 把归零的币也纳入统计(扫已经死掉的池)
- [ ] 加入资金占用成本:按"钱趴多久才等到一根针"折算
- [ ] 扩大样本:多条链、更长窗口、更多池

---

## 9. 沉淀

1. **AMM 的价格是连续的,所以"会不会成交"是确定的** —— 这让链上限价策略天然可回测,
   比交易所策略好验证得多。
2. **回测出 100% 成功率 = 判据有问题。** 这次是"用最高价当出场价"。
3. **按今天的榜单扫历史 = 幸存者偏差。** 死掉的样本不在榜上,而它们正是风险所在。
4. **易逝的数据要采,可回溯的数据随时拉。** 分清这两类,能省下大量无谓的等待。
