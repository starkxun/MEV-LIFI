## 一、当场出局的四个

### ③ 新币上线差价套利 ❌ 第①问不过

**已经实测证伪过。** 见 [16 天原型](16天原型.md) 里的 DOS 调查:

```
群里说:  项目方加错池子,1 DOS ≈ 0.05 USDT,快去套
实际:    · 建池价是 0.10(整数,故意设的)
         · 0.05 是【流动性区间的下界】,不是可成交价
         · 24.8 小时零成交,首笔实际成交在 $1.4376
         · 谁在开盘买进,现在浮亏 93%
```

**根本问题:新币没有第二个场子。** 「在 0.05 买进」的终点是**持有那个币**,
不是回到 USDT —— 闭不了环。

> **例外:如果同一个币【同时】在两个所上线**,那才是真的跨所价差,
> 那就变成第 ① 条了。判断标准仍是「另一条腿在哪」。

### ④ 资金费率变动套利 ❌ 第①问不过

赌资金费率往哪个方向变。**这是预测,不是套利** —— 没有闭环,
猜错就是真亏。

### ⑤ 刷返佣和积分 ❌ 第①问不过

**作者自己的文档就写明了**这是「刷交易量撸空投或返佣」。

> **这跟套利是两回事**:那种情况下你不是在赚价差,是在**买积分**,
> 手续费是成本不是障碍。想清楚自己在做哪一件。

积分值多少钱,在拿到之前无法知道 —— 所以它连"成本可测"都做不到。

### ⑧ 狗庄/做市商砸盘拉盘 ❌ 第①问不过

带故事的方向性投机。**赌别人接下来会怎么操盘。**

## 二、值得做的三个(按优先级)

### ★ 第 ② 条:现货 + 永续套保

**这可能是我们两周一直漏掉的更大的池子。**

#### 为什么漏掉

我们一直在测**跨所价差**:

```
跨所对冲     赚 |rate_A − rate_B|
现货+永续    赚 rate_A 的【完整值】
```

实测差距:

```
SNDK    币安 -47.0%  Bybit -47.7%   跨所差  0.7%   单所绝对值 47.7%   68 倍
APR     币安 +62.2%  Bybit +65.6%   跨所差  3.4%   单所绝对值 65.6%   19 倍
SOL     币安 +10.9%  Bybit +10.9%   跨所差  0.0%   单所绝对值 10.9%   —
```

**两个所同向高费率时,跨所差为零,但现货+永续能吃满。**
全市场 ≥20%:跨所口径 5 个,绝对值口径 **8 个**。

这解释了 08-13 那次的困惑 —— SKHYNIX 一度两边都是 +157%,
我们算出「净 carry 归零」就撤了,**那时候做现货+永续能吃 157%。**

#### 但第一轮扫描就泼了冷水

```
[10:54:39] 全量 27  跨所≥20%: 8  **单所≥20% 且有现货: 1**
           APR +144%@Byb(无现货)   SKHYNIX +125%@Bin(无现货)
```

**高绝对费率的币,大多没有现货市场** —— 尤其代币化股票
(SKHYNIX、SOXL 这些只有永续)。

`carry_watch --scan` 现在会把 `spot` 字段落盘,两周后能直接量出
**「高绝对费率 + 有现货」的交集有多大**。

#### 优点和代价

```
✅ 同一个交易所,两条腿之间【没有跨所基差风险】
   —— 08-13 那次 ±$0.004 的来回浮亏,主要来自跨所基差
✅ 没有跨所单腿风险(仍有同所单腿,但窗口更小)
✅ 吃的是完整费率,不是差值

🔴 手续费从 8 bps 涨到 20 bps(现货腿贵)
🔴 要真持有那个币(托管 + 可能要提币)
🔴 费率为负时要【做空现货】= 借币,复杂度高一截
```

#### 下一步

```
☐ 等扫描数据,量出「有现货 + 绝对费率 ≥20%」有几个币、能撑多久
☐ taoli 里配 A=现货 / B=同所永续,先单边验证
☐ 用最小名义跑一次,量同所单腿率(应该低于跨所)
```

### ★ 第 ⑥ 条:Bitget 资金费逃票

**这是「离散结算」那个洞见的攻击面用法。**

#### 机制

资金费**只在结算时点收**。所以:

```
结算前平仓  →  不持仓,不用付
结算后重开  →  躲过这一期
```

#### 判据很干净

```
值得逃票  ⟺  要付的资金费  >  2 × 往返手续费
```

因为逃一次要多付一进一出。按永续 maker 2 bps 算:

```
一进一出 4 bps  →  逃票成本 4 bps
要躲的资金费 > 4 bps 才划算
```

**4 bps 对应的单期费率是 0.04%** —— 不算特别罕见。

#### 但有三个坑

```
① taoli 做不了 —— 它的触发器是【价差】,不是【时间】
   逃票需要"距离结算还有 N 分钟"这种时点触发
   → 只能自己写脚本或手动掐点

② 平仓/重开之间价格会动 —— 那段裸露期的风险没算进去

③ 各所结算规则不同 —— Bitget 之所以被单独点名,
   可能是它的规则更容易逃(比如快照方式)。**这个要自己验证。**
```

#### ❌ 结论(2026-08-15):对我们做的结构**根本不适用**

先说最要命的一条,和频率无关:

> ### 🔑 逃票是给【单边持仓】用的,不是给对冲仓用的
>
> 你两条腿反向,一条收一条付,**净收**。
> 逃票要么两条腿一起逃(净收益也一起没了,白折腾),
> 要么只逃一条 —— 那段时间**另一条腿裸露**,
> 用几个 bps 去换方向性风险,是个坏交易。
>
> **它是给"因为别的原因持有单边永续、想少付点资金费"的人用的。**

其次,就算是单边持仓,频率和金额也不支持:

```
逃票成本(平+开一条腿)         门槛     超过的比例
加密·挂单 (2+2)               4.0 bps      5.0%
加密·吃单 (5+5)              10.0 bps      1.9%
代币化股票·吃单 (4+4)          8.0 bps      2.4%
★代币化股票·挂单 (0+0)         ~0           83.8%
```

样本:22 个所 × 1848 币 = **8939 个(所×币)组合**的当前单期费率。

**单期 |费率| 中位只有 0.50 bps**(p90 = 2.00,p99 = 16.41)。

折成钱:

```
省 0.50 bps(中位)→ 要 $20,000 名义额才省下 $1
省 2.00 bps(p90) → 要  $5,000
省 16.4 bps(p99) → 要    $625
```

**你的仓位是 $16。中位那一次逃票省 $0.0008。**

唯一有意思的是最后一行:**代币化股票挂单手续费实测为 0,所以逃票在这一档是免费的**,
任何非零费率理论上都值得逃(83.8% 的时刻)。但代价不是手续费,是
**挂单可能挂不上 + 空窗期的价格风险**,而那两个我们都还没量。

## 三之前:第 ⑨ 条 BNB IDO —— 实测证伪全过程

**这是九条里唯一花时间实测的**,值得完整记一遍,因为方法可复用。

### 为什么它一度最有吸引力

前面所有方向都死在同一件事上:**机会什么时候来,不知道。**

```
清算       要等暴发日
跨所 carry 要等费率张开
新池       要蹲上线
```

**全是被动等待。而事件驱动天然解决这个 —— IDO 的时间是公布的。**

### 先写出机制猜想,再去验

**不能先找规律再编解释。** 猜想是:

```
Launchpool 要质押 BNB 挖新币
  ↓
想挖但不想承担 BNB 涨跌的人,会【买现货 BNB + 做空 BNB 永续】对冲
  ↓
大量人做空永续 → 永续价格压到现货之下
  ↓
资金费【转负】→ 空头(挖矿的人)付钱给多头
  ↓
所以:IDO 期间做多 BNB 永续,能收挖矿的人付的钱
```

**这个猜想是可证伪的:如果成立,IDO 期间 BNB 资金费应该系统性偏负。**

### 障碍:我没有 IDO 日历

**但不需要。** 逻辑是:

```
如果 IDO 造出了可交易的资金费异常  →  数据里必然存在异常时段
如果数据里【任何时候】都没有异常  →  IDO 没造出异常
```

**不用知道事件何时发生,只要证明「异常从未发生过」。**

> 这和[概念入门第 13 课](永续与资金费-概念入门.md)那条是同一个套路:
> 当时我不知道 SKHYNIX 跟哪个市场的交易时段,
> **就用成交量的形状去定位开市时间,而不是查日历。**
>
> **绕开你不知道的量,而不是去猜它。** 这是第二个应用实例。

### 结果:两条腿都不成立

**资金费维度**(166 天 / 500 期):

```
均值      +2.90%/年
中位      +0.00%          ← 大部分时候正好卡在基准线
为负比例   1.2%
区间      [-13.9%, +21.5%]

显著偏负的日子:3 天 / 168 天,最负只有 -4.6%/年
```

**168 天里没有任何一次异常,大到能覆盖 8 bps 往返手续费**
(按 +2.90% 算要持有 10 天)。

**价格维度**(跨所基差,1000 小时):

```
              均值        标准差      区间
BNB       +11.05 bps    【2.05】   [ +3.2, +16.8]
SOXL         —           4.18      [-19.1, +14.9]
SKHYNIX      —           8.69      [-47.2, +27.3]
```

**BNB 基差标准差只有 2.05 bps —— 比往返手续费 8 bps 还小。**

而且均值 +11 bps 长期稳定为正,那是**结构性偏移**,不是可套利的波动。

> **波动范围跨不过成本,连"等一个好入场点"都没意义。**

### 结论

```
❌ 资金费维度:168 天零异常
❌ 价格维度:基差标准差比手续费还小
```

**第 ⑨ 条证伪。** 而且这次证伪只花了两条命令、十分钟。
