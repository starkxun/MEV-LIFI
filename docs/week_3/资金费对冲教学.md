## 第 0 课:为什么这个方向和前面四周都不一样

我们这四周否掉了四个方向,死因只有两种:

```
① 延迟竞赛赢不了      原子套利、公开喂价清算
② 价值被拍卖回收      SVR 吃掉 89%,Atlas 上 Top1 占 84.6% 的中标
```

两种都是**赢家通吃**:机会是一份,谁先拿到就没别人的了。
**小而中立的玩家在这种结构下天生吃亏**,这不是努力能改变的。

**资金费不是这个结构。**

资金费是**按未平仓量、按比例、付给所有空头**的。
没有人能"抢在你前面拿走一笔资金费" —— 你持有多少仓位,就按比例拿多少。

> **这是四周以来第一个不存在赢家通吃的方向。**
> 结构不同,不是程度不同。

代价是:**它也不是套利,是 carry(持有报酬)。** 第 7 课细说。

## 第 1 课:资金费到底是什么

永续合约没有交割日。那怎么让它的价格贴着现货走?

**靠一笔周期性的转账,叫资金费。**

```
永续价格 > 现货价格   →  说明多头太热
                      →  多头付钱给空头     (资金费为正)

永续价格 < 现货价格   →  说明空头太热
                      →  空头付钱给多头     (资金费为负)
```

**它不是交易所收的手续费,是多空之间的转账。** 交易所只是搬运工。

Backpack 上**每小时结算一次**(注意:不是常见的 8 小时,别写死):

```bash
python3 funding_probe.py floor
```

```
结算间隔 1 小时,一年 8760 次
```

## 第 2 课:carry 怎么组

要**收**资金费(而不是付),在资金费为正时:

```
        现货买入 1 个 ETH          ←  你持有 ETH,涨跌都跟你有关
   +    永续做空 1 个 ETH          ←  反向对冲掉涨跌
   ────────────────────────
   =    净价格敞口 ≈ 0
        但你是空头  →  每小时收一笔资金费
```

**两条腿的价格波动互相抵消,剩下的就是资金费。**

这就是为什么它满足我们的[闭合检查器](闭合检查器设计.md)第 ① 问
—— 起点是 USDC,终点也是 USDC,**token 口径闭环**。
(对比 DOS 那个池子:买进去之后你持有的是 DOS,闭不上环,那是投机。)

## 第 3 课:动手 —— 先量地板

**任何判断之前,先知道要跨过多高的门槛。**

```bash
python3 funding_probe.py floor
```

```
=== Backpack Tier 1 费率(官方文档,bps)===
  spot_maker    8       spot_taker   10
  perp_maker    2       perp_taker    5

=== 往返手续费地板(开仓 + 平仓,现货腿 + 永续腿)===
  全 maker   20 bps
  全 taker   30 bps
```

**为什么是 4 笔手续费**:开仓时现货买一笔、永续开空一笔;平仓时各再来一笔。

然后换算成"需要多高的年化才回得了本":

```
持仓   1 天回本  →  需要年化    73.00%
持仓   3 天回本  →  需要年化    24.33%
持仓   7 天回本  →  需要年化    10.43%
持仓  30 天回本  →  需要年化     2.43%
持仓  90 天回本  →  需要年化     0.81%
```

> ### 🔑 这张表就是整个策略的形状
> **持仓时间越长,手续费越不重要。** 持 90 天的话,0.81% 年化就够回本。
> 反过来说:**这不是一个"快进快出"的策略**,越频繁调仓,地板越吃人。

## 第 5 课:把窗口拉长 —— 真相

```bash
python3 funding_probe.py history BILL_USDC_PERP
```

对同样这 5 个币,拉满历史再看一遍:

| 币 | 4 天窗口 | 长窗口(真相) | |
|---|---|---|---|
| BILL | +126.01%,同号 **100%** | **+13.57%**(88 天),同号 81% | **高估 9.3 倍** |
| SKR | +70.60%,同号 **97%** | **−33.44%**(201 天),两半反号 | **符号反了** |
| WLFI | +16.05%,同号 **100%** | **−2.89%**(344 天),两半反号 | **符号反了** |
| WLD | +13.23%,同号 **100%** | **−11.25%**(344 天),同号 55% | **符号反了** |
| XPL | +14.05%,同号 99% | +9.74%(320 天),同号 85% | ✅ 一致 |

**5 个"100% 稳定"的候选,3 个在长窗口下符号是反的。**

如果按短窗口下单做空 SKR 收资金费,**你实际上会一直在付钱。**

> ### 🔑 这一课是整份文档最重要的
>
> **这是我在这个项目里第二次犯同一个错。** 上一次是清算:
> 用 14 天窗口算年化,得出"市场一年只值 $18,682",
> 扫了 160 天才发现真值是 $721,542 —— **低估 39 倍**。
>
> 病根一样:**这类数据的分布是偏的,短窗口测到的是"最近碰巧发生了什么",
> 不是"通常是什么"。**
>
> **可迁移的判据:任何"年化"数字,先问它是从多长的样本外推的。**
> 4 天外推一年 = 放大 91 倍,任何噪音都会被放大 91 倍。

### 怎么防

脚本里加了两个硬指标,单看年化不够:

```
同号占比   全部样本里,资金费保持同一方向的比例
两半对比   把历史劈成近一半 / 远一半,分别算年化
           **如果两半符号相反,直接出局** —— 说明这个币的资金费在换方向
```

## 第 7 课:它不是套利,是 carry

这个定性必须说清楚,因为它改变了"成功"的定义。

**套利**:两个场子价格不一致,你同时买卖,锁定差价。风险来自执行。

**carry**:你持有一个头寸,因为承担了某种风险而被支付。风险来自持有。

资金费 7~15% 的年化,**是在为下面这些风险付你钱**:

| 风险 | 说明 |
|---|---|
| 交易所对手方 | 钱放在 CEX 上。FTX 的教训 |
| ADL / 爆仓 | 极端行情下被强制减仓,对冲断腿 |
| 稳定币脱锚 | 整个 U 本位假设失效 |
| 资金费反向 | 即使 92% 同号,也有 8% 的时段你在付钱 |
| 单腿 | 入场、出场各一次暴露窗口 |

> **所以不存在"这个 edge 存不存在"的问题** —— 钱明摆着在付。
> 真正的问题是:**付给我的,够不够抵这些风险?**
>
> 这是风险偏好问题,不是研究问题。**研究到此为止,决策归你。**

还有一个全新的东西:**托管风险**。
前四周我们做的一切要么纯只读,要么押 0.1 ETH($192)。
**这次是真金白银放在别人服务器上,是个我们没碰过的风险类别。**

## 第 8 课:Backpack 的 100ms 减速带

调研文档里挖到的,中文圈几乎没人提,但它直接影响你怎么下单:

> Backpack 对**所有 taker 订单**(现货 + 期货)统一施加 **100ms 减速带**。
> 只有带 `postOnly` 的订单免疫。撤单不受影响。

三条后果:

```
① 吃单入场的成本 > 30 bps —— 还要加上那 100ms 里盘口的漂移
② 如果 Backpack 这条腿是 taker,它必然比另一条腿晚 100ms
   → 单腿暴露从"网络抖动的随机量"变成"至少 100ms 的确定量"
③ 唯一解法是 postOnly(纯挂单),但那可能不成交 → 又回到单腿问题
```

**这是明确的取舍,没有免费午餐。**

⚠️ 有一个**至今没有答案**的问题(调研文档里的 Q7'):
Taoli Tools 的 VA/VB 限价单,下的是普通限价单还是 `postOnly`?
**如果是普通限价,价格穿过盘口时照样会吃到那 100ms。**
这条在真下单之前必须确认。

## 第 9 课:还有一项没测,所以不出总数

按我们自己在[成本模型](../week_2/成本模型教学.md)里定的规矩:
**主项没测出来,就拒绝打印合计。**

```
✅ 手续费地板     20 bps(maker)/ 30 bps(taker)   ← 已测,官方文档
✅ 资金费收入     长窗口筛选后 7~19% 年化           ← 已测,380 天样本
⚠️ 单腿发生率     **待定**                          ← 没测
❓ 减速带滑点     待定                              ← 需要采样盘口
```

**单腿发生率是唯一能杀死这个策略的未知数。**
如果它是 50 bps 量级,7% 的年化直接被吃光。

而它**只能靠小额真跑测出来** —— 没有公开数据,链上也查不到。
这就是为什么下一课的第 4 步必须真下单。

## 第 10 课:★ 我该从哪开始

**五步,前三步零成本零风险,做完再决定要不要花钱。**

### 第 1 步:自己跑一遍筛选(今天,10 分钟,零成本)

```bash
python3 funding_probe.py floor
python3 funding_probe.py screen --top 40 --out shadow/funding_screen.json
```

**目的不是找币,是让这几个数字变成你自己的**,而不是我告诉你的。
特别注意看:年化最大的那几个,同号占比是多少。

### 第 2 步:亲手复现那个陷阱(今天,5 分钟,零成本)

```bash
python3 funding_probe.py rates --limit 100      # 短窗口,好看
python3 funding_probe.py history SKR_USDC_PERP  # 长窗口,反号
```

**亲眼看一次 +70.60% 变成 −33.44%。**
这个体感比读十遍"要注意样本长度"有用。

### 第 3 步:挂着跑两周,验证筛选的稳定性(零成本)

把 `screen` 挂成每天一跑,存快照:

```bash
# 加进 crontab,或者用 tmux 挂一个循环
python3 funding_probe.py screen --top 40 --out shadow/funding_$(date +%F).json
```

两周后回答一个问题:**第 1 天筛出来的 8 个币,第 14 天还在名单里吗?**

```
还在      →  筛选判据是稳的,可以进第 4 步
换了一半  →  判据不够严,回去加条件(比如同号提到 85%)
```

> **这一步不能跳。** 我们已经在两个方向上栽在"用一次快照当结论"了。

### 第 4 步:小额真跑,只为测单腿(要花钱,但可控)

前提:第 3 步的名单稳定。

```
场地      Backpack,VIP0 免费额度($5,000 以内)
标的      名单里同号占比最高的那个(现在是 LINK,92%)
规模      最小可下单量。**目的不是赚钱**
模式      Taoli Tools 的 Once,不要用 Loop
次数      开平 20~30 次
```

**只记三个数:**

```
① 实际成交价差 vs 屏幕价差的差   ← 减速带 + 滑点的真实代价
② 单腿发生率                     ← 20~30 次里断了几次
③ 端到端延迟
```

**拿到这三个数之前,不要付 VIP,不要开 Loop,不要加规模。**

### 第 5 步:把 ③ 那一栏填上,重算总账

单腿发生率填进成本模型,这时候才第一次有资格打印「总收益」。

```
净年化 = 资金费年化 − 手续费摊薄 − 单腿概率 × 平均补腿损失 − 减速带滑点
```

**如果这个数扣完还是正的,才谈规模。**

## 附:这一课学到的方法

1. **任何"年化"先问样本多长** —— 4 天外推一年 = 放大 91 倍
2. **看方向稳定性,不只看幅度** —— 年化最大的往往最不稳
3. **把历史劈两半对比** —— 两半反号是最便宜的证伪手段
4. **有待定项就不出总数** —— 这条已经救过我们两次
