# 一、这条线是什么

在两个交易所对同一个标的开**方向相反、数量相同**的永续仓位。

```
A 所做空 q 手        B 所做多 q 手
    ↓                     ↓
价格涨跌互相抵消 —— delta 中性
    ↓
赚的是两个所【资金费率之差】
```

正式名称:**cross-exchange basis arbitrage**,是期货 cash-and-carry 的跨市场版本。

# 三、机制:盈亏到底由什么决定

## 3.1 推导

```
空 S 所 q 手 @ P_S⁰,多 L 所 q 手 @ P_L⁰

PnL = q(P_S⁰ − P_Sᵗ) + q(P_Lᵗ − P_L⁰)
    = q[P_S⁰ − P_Sᵗ + P_Lᵗ − P_L⁰]
    = q[(P_S⁰ − P_L⁰) − (P_Sᵗ − P_Lᵗ)]
    = q × (开仓基差 − 当前基差)                    ∎
```

> **价格水平项被完全消去。标的从 56 涨到 200,盈亏一分不变。**
> 这就是 delta-neutral 的定义:组合对标的价格的一阶敏感度为零。

## 3.2 用真实账单验证

HYPE 08-15 那次误平,完整往返:

```
Bybit 多  56.760 → 56.410   =  -0.0315
币安  空  56.764 → 56.494   =  +0.0243   ← 交易所显示 +0.0243  ✅
两腿合计                       -0.0072

公式:0.09 × (+0.004 − +0.084) = -0.0072   ✅ 分毫不差
```

**这个公式是对的,不是近似。**

## 3.3 所以整条策略只有两个收益来源

```
① 资金费差    每次结算划转一次(离散,不是连续利息)
② 基差变化    开仓基差 − 平仓基差
```

而成本有三项:**手续费、盘口价差、单腿风险**。

# 四、成本:每一项的实测值

## 4.1 手续费(从 10 笔真实账单反推 + 官方费率表对账)

单腿单边(bps):

| | Bybit maker | Bybit taker | 币安 maker | 币安 taker |
|---|---|---|---|---|
| **代币化股票** | **0.00** | 2.75 | **0.00** | 4.00 |
| **加密** | 2.00 | 5.50 | 2.00 | 5.00 |

往返(两腿 × 开平 = 4 笔):

| | 双边吃单 | 混合 | 双边挂单 |
|---|---|---|---|
| **代币化股票** | 13.50 | 8.00 | **0.00** |
| **加密** | **21.00** | 14.00 | 8.00 |

**我们前四周一律按 8 bps 算 —— 加密低估 163%。**

交叉验证:HYPE 误平的四笔手续费账单合计 **0.0107 USDT**,
`21.00 bps × $5.08 = 0.01067`。分毫不差。

## 4.2 盘口价差 —— 和手续费同量级,以前完全没计入

```
开仓 = (空腿买一 − 多腿卖一) / mid       ← 可成交的入场价差
关仓 = 同方向平仓时的价差
开仓 − 关仓 = 【往返盘口成本】= 两所买卖价差之和
```

CAP 实测验证:

```
币安价差 1.55 bps + Bybit价差 7.75 bps = 9.30 bps
QQQ.BOT 的 开仓−关仓 = 6.1 bps          ✅ 同量级
```

六个币实测往返盘口成本:**6~18 bps**。

**这意味着:即使手续费为 0(代币化股票双边挂单),盘口价差仍在。
「零手续费」不等于零成本。**

## 4.3 单腿风险 —— 唯一没测出来的那项

```
⚠️ 限价单挂不上的概率  —— 没有任何公开来源,只能自己试
```

零手续费的代价就是它。**在拿到这个数之前,「双边挂单 0 bps」只是上界。**

# 五、收益:全市场的真实分布

## 5.1 606 个币的 30 天口径(Coinglass,22 个所 × 1848 币)

数据可信度先验过:8H 结算的大币直连交易所对账,**16/16 吻合,偏差 ±5%**。

```
币安 ∩ Bybit 且两边有 30 天历史:606 个币

当前净年化与 30 天累计【反号】   465/606 = 77%   ← 只看实时就会踩的坑
                     【同号】   141/606 = 23%

|30 天净年化| 分布:
  中位   3.66%
  p75    7.51%
  p90   15.85%
  p99   71.36%
  最大 410.76%
```

> ### 🔑 中位币的跨所净 carry 是年化 3.66%
>
> 扣掉加密双边挂单 8 bps 往返 + 6~18 bps 盘口价差,**净值为零。**

## 5.2 45 小时实测:老实持有会怎样

37 个币,方向在**起点**按当时净年化选(不是事后诸葛):

```
净收益为正            21/37 = 57%
净收益 > 吃单往返费     2/37 =  5%
净收益 > 挂单往返费     9/37 = 24%
```

但分布是这样的:

```
中位 +0.37 bps   均值 +7.64 bps   合计 +282.5 bps
最大 +276.5(COTI)→ 占合计的 98%

去掉 COTI:37 个币 45 小时,合计 +6.0 bps
```

**均值是中位的 21 倍。厚尾。**

中位数年化:`0.37 × 8760/45 = 0.72%/年`。

## 5.3 事后挑方向会夸大 5.1 倍

```
起点选向 中位 +0.37 bps
事后最优 中位 +1.90 bps
```

**任何"回测显示能赚"的说法,先问方向是什么时候定的。**

## 5.4 追高 carry 窗口:结构性死亡

```
≥10% carry 的窗口 511 个 → 只有 9% 跨过结算 → 只有 2% 能覆盖手续费
≥20%              427 个 → 只有 9% 跨过    → 只有 10% 能覆盖
≥40%              275 个 → 只有 10% 跨过   → 只有 21% 能覆盖
```

**窗口时长中位 5~8 分钟,而结算间隔是 4~8 小时。**

> 91% 的高 carry 出现又消失,期间一分钱没换手。
> **这不需要更多数据 —— 它是「窗口时长 vs 结算间隔」的算术。**

复合概率:≥40% 的窗口真正付得起自己成本的概率 = 10% × 21% = **2.1%**。

# 六、唯一的赢家:COTI,以及它说明了什么

## 6.1 它赚了什么

```
1 小时结算,45 小时内 26 次结算(每边)
币安 26 次费率【全部为负】,合计 -551.7 bps
Bybit 合计 -828.2 bps

空币安(付 551.7)+ 多 Bybit(收 828.2) = 【+276.5 bps】
```

$16 仓位 45 小时赚 **$0.455**。比 SNDK 一天赚两厘强 200 倍。

## 6.2 机制:资金费上限的不对称触顶

```
币安 ±2.000%   Bybit ±2.500%   MEXC ±3.000%   Bitget ±1.875%
```

**各所上限不同。** COTI 那次 Bybit 打到 -2.0000%(触顶),
币安最差才 -0.599%(没触顶)。**差额就是你的收益。**

## 6.3 但必须是【单边】触顶

ACE 实测反例:

```
币安  本期 -2.0000%   ← 触顶
Bybit 本期 -2.0000%   ← 也触顶
净 = 0.0000%
```

**两边同时触顶,差值归零。** 而且失衡从资金费通道**转移到价格通道**:

```
基差 = (币安 − Bybit) / Bybit = -259.8 bps    历史分位 -9σ
```

> ### 🔑 上限锁住一个通道,压力会从另一个通道冒出来
>
> 资金费只能表达到 ±2%,剩下的压力从价差里冒出来。
> 而 2.6% 的价差通常意味着结构性原因(下架、合约变更、逼空),不是免费午餐。

## 6.4 COTI 也暴露了我们自己筛选器的一个错

```
COTI 每次结算:61% 亏钱,但总额 +276.5 bps
  赢的 11 次  平均 +42.1
  输的 17 次  平均 -11.0     赢面是输面的 3.8 倍
```

我原来的判据「净为负 ≥25% 就红旗」**会系统性排除正偏态赢家**,
而 t 检验(看均值)是通过的 t=2.9。**两个判据自相矛盾。**

**已修正:负比例不再单独否决,只有当均值也立不住时才是红旗。**

# 八、为什么不成立 —— 四层证据

```
① 追窗口     91% 的高 carry 窗口跨不过结算    ← 结构性,算术问题
② 持有       中位币年化 0.72~3.66%,扣成本为零  ← 606 币 / 37 币两个口径一致
③ 挑赢家     98% 的收益来自 1 个币,且方向会翻   ← 厚尾,不可依赖
④ 可交易性   专业筛选器 487 条 → 你能做的 0 条   ← 流动性,不是费率
```

**四层是独立的,任何一层都足以否掉。**

## 深度决定的天花板

即使抓到 COTI 那种:

```
Bybit 买一深度 $114 → $79(一小时内变化)
就算能吃 10 倍书面深度,单次也就 $500~1000
× 276 bps = $14~28 / 次
```

**加本金不解决问题 —— 深度就那么多。**

# 九、什么情况下它会成立

诚实地说,这条线不是"永远不行",而是"以你现在的位置不行"。

| 要改的 | 需要什么 | 你现在 |
|---|---|---|
| **本金** | 万级以上,才够穿过深度和固定成本 | $30 |
| **执行** | 程序化、多所、分批收敛 | 网页手动点 |
| **覆盖** | 22 个所全开户,不是 2 个 | 2 个 |
| **信息** | 别人看不到的通路 | 全公开 |

**其中「覆盖」是最便宜的一项** —— 487 条候选里 96.7% 卡在
"你没在那个所开户"。开 Gate / KuCoin / MEXC 三个户,
候选池会从 16 条涨到几百条。

**但那只解决第 ④ 层,前三层不变:**
窗口仍然跨不过结算,中位仍然是零,收益仍然集中在一个币上。

## 方法(和加密无关)

```
① 资金费是离散事件,不是连续利息
② 单期费率必须按各所结算间隔归一化才能比
③ 对冲组合的盈亏只由基差决定,与价格水平无关
④ 历史要按【你将要开的方向】读,无方向的统计会把"反着做能赚"误报
⑤ 「多数期数为正」和「总额为正」不是同一件事(正偏态赢家常态就是多数期亏)
⑥ 事后挑方向会夸大 5 倍
⑦ 收益率和可放入的资金量是两个独立的量,分开验
⑧ 假设和实测必须长得不一样,否则一个月后分不清
```
