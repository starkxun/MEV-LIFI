# 金融基础:一条为「已经在做」的人设计的补课路线

> 2026-08-14
>
> **不是科班路线。** 目标是补上这四周里**实际绊倒过我们**的那些洞,
> 而不是系统学一遍金融。每一条都对应一个具体的错误。

---

## 零、先说不用学什么

这比"该学什么"更重要,因为它省下的是几百小时。

```
❌ 期权定价(Black-Scholes、希腊字母)   —— 你不交易期权
❌ 投资组合理论(CAPM、有效前沿)        —— 你不做资产配置
❌ 公司金融(估值、并购、资本结构)      —— 完全无关
❌ 宏观经济学                          —— 对你的策略没有输入
❌ 会计                                —— 无关
```

**你做的是「两条腿对冲、赚结构性价差」,这在金融里是一个很窄的分支。**
不要被"学金融"这个说法带偏。

## 一、你已经在做的东西,它们的正式名字

**先把已有的经验挂到正确的名词上** —— 这样查资料才找得到门。

| 你做的事 | 正式名称 | 一句话 |
|---|---|---|
| 现货多 + 永续空,赚资金费 | **cash-and-carry / basis trade** | 期货理论最经典的交易 |
| 两所反向开仓,赚费率差 | **cross-exchange basis arbitrage** | 上面的跨市场版本 |
| 资金费让永续贴住现货 | **convergence mechanism** | 替代交割日的强制收敛 |
| 两所价差 | **basis**(基差) | 期货价 − 现货价,这里是两个永续之差 |
| 价格涨跌被抵消 | **delta neutral** | delta = 对标的价格的敏感度 |
| 基差来回晃 | **mean reversion / OU 过程** | 见第三节,这是最大的缺口 |
| 挂单便宜吃单贵 | **maker-taker fee model** | 微观结构的核心机制 |
| 只成交一条腿 | **legging risk** | 非原子执行的固有风险 |

> **光是知道「我做的叫 cash-and-carry」,就能让你搜到几十年的文献。**
> 之前你搜"资金费套利",搜到的只有中文社区帖子。

## 二、四个真正的缺口(按我们犯过的错排序)

### 缺口 1:时间序列 —— 均值回归 vs 随机游走 ★最要紧

**犯过的错:** 我用 `噪音 = 7 bps × √T` 估基差风险,**方向就是错的**。

实测打脸:

```
持有      实测     随机游走预测    OU 上界(√2·σ∞)
   8h     2.27         2.27           3.10
 168h     3.07        10.40           3.10
                    高估 3.4 倍      差 1%
```

**基差是均值回归的,方差会饱和。** 这个模型叫 **Ornstein-Uhlenbeck 过程**,
离散形式就是 **AR(1)**。

**为什么这个缺口最贵:**

```
随机游走  →  持有越久风险越大  →  应该快进快出
均值回归  →  风险有上界,收益线性累积  →  【应该拿住】
```

**两个模型给出完全相反的策略。** 我们差点因为这个错误而否掉整条路线。

**要学会的三件事:**

```
① 半衰期怎么估    ΔB_t = λ(B_{t-1} − μ) + ε,半衰期 = −ln2/ln(1+λ)
② 平稳性怎么检验  ADF 检验、Hurst 指数
③ 最优阈值        知道 λ 和 σ 之后,进出场阈值有解析解,不用拍脑袋定 z>0.5
```

**推荐:**

- **Ernie Chan《Algorithmic Trading: Winning Strategies and Their Rationale》第 2 章**
  —— 均值回归、协整、ADF、Hurst、半衰期,全在这一章,而且直接给代码。
  **这一章就值整本书的钱**,一个下午能看完。
  (Chan 的书在学术圈评价一般,但工程实用性很强,适合你现在的阶段。)
- 想深一点:**Tsay《Analysis of Financial Time Series》** —— 学院派,啃起来慢。

### 缺口 2:统计 —— 厚尾、抽样、选择偏差

**犯过的错,四次:**

```
14 天窗口年化     →  低估 39 倍      (窗口太短)
4 天窗口看资金费  →  高估 9.3 倍,3/5 符号反了
42 天分布定阈值   →  实际触发率 8% 而非 38%(窗口太长)
两半比值筛稳定性  →  系统性筛掉所有机会(选择偏差)
```

**四次都是统计问题,不是金融问题。**

**核心概念:**

```
厚尾分布      中位 $0.03、均值 $81 —— 差 2700 倍,均值被极值主导
基准率        「任意喂价更新」命中 36.8%,但随机也能到 100%
选择偏差      只记录高 carry 的时刻 → 无法回答「正常状态是什么」
幸存者偏差    只看通过筛选的那批,永远发现不了自己在反向选择
```

**推荐:**

- **Taleb《Statistical Consequences of Fat Tails》** —— **arXiv 免费**。
  前 6 章讲清楚"为什么厚尾下均值没意义、要多少样本才够"。
  数学有点重,但**跳过证明只看结论也很值**。
- **López de Prado《Advances in Financial Machine Learning》**
  —— 关于**回测过拟合、样本唯一性、组合净化交叉验证**那几章,
  正好对应我们的选择偏差问题。书很密,**只读第 7、11、12 章**。

### 缺口 3:期货与基差理论

**你已经在做 cash-and-carry,但没学过它的理论。**

**核心概念:**

```
cost of carry   持有成本 = 资金成本 + 仓储 − 便利收益
convergence     到期日强制收敛;永续用资金费替代
basis risk      对冲不完美的残差风险 —— 你每天在看的那个
contango / backwardation   期货升水 / 贴水
```

**为什么值得学:** 期货基差交易有**几十年文献**,
你遇到的每个问题(基差风险、展期、对冲比率)都被研究透了。

**推荐:**

- **John Hull《Options, Futures, and Other Derivatives》第 1~5 章**
  —— 教科书里的标准。**只读这五章**,大约 100 页,两三天。
  第 3 章「Hedging Strategies Using Futures」讲的就是你在做的事,
  包括**最优对冲比率**(你现在是 1:1,理论上未必最优)。

### 缺口 4:市场微观结构

**犯过的错:** 一开始不知道 maker/taker 差 2.5 倍、不知道 100ms 减速带、
不知道盘口深度决定实际成交价。

**核心概念:**

```
bid-ask spread      买卖价差的构成
market impact       大单的价格冲击
adverse selection   你的对手方为什么愿意和你成交
maker vs taker      提供流动性 vs 消耗流动性
order types         限价、市价、postOnly、IOC、FOK
```

**为什么重要:** 你所有的成本模型都建在这上面。
**8 bps 手续费地板不是常数,是微观结构的产物。**

**推荐:**

- **Larry Harris《Trading and Exchanges: Market Microstructure for Practitioners》**
  —— 这个领域的圣经,**写给从业者而不是学者**,几乎没有数学。
  600 多页,但**可以当字典查**:遇到不懂的机制就翻对应章节。
  优先读:订单类型、流动性、做市商那几章。

## 三、你已经读过的论文,现在能读懂更多了

这四周读的那几篇,当时可能只抓到结论。**补完上面的基础之后重读,会看到方法:**

```
LVR(Loss-Versus-Rebalancing)      → 做市商的逆向选择成本
CEX-DEX Extracted Value(AFT 2025) → 用 markout 估收益,这是微观结构标准方法
There Will Be Spam                 → 状态不变交易的定义与分类方法
Signals and Spoils                 → 投机型 OEV
```

**特别是 CEX-DEX 那篇的 markout 方法** —— 它解决的问题和你现在一样:
**如何在只能看到一条腿的情况下估计真实收益。**

## 四、一条实际的顺序

**按「什么能立刻用上」排,不是按难度排。**

```
第 1 周   Chan 第 2 章(均值回归 + 半衰期)
          → 立刻能用在你的基差上,算出最优进出场阈值
          → 这是四条里唯一【今天就能变成钱】的

第 2 周   Hull 第 1~5 章(期货与基差)
          → 把你在做的事挂到正确的理论框架上
          → 顺便学会最优对冲比率

第 3~4 周 Taleb 前 6 章 + de Prado 第 7/11/12 章
          → 治我们犯过四次的取样病
          → 这个不学,以后还会再犯

持续      Harris 当字典查
          → 不要通读,遇到机制不懂时翻
```

**总时长:一个月的业余时间,不是几年。**

## 五、一个判断标准

学到什么程度算够?**看能不能回答这几个问题:**

```
☐ 我这个基差序列是平稳的吗?怎么检验?
☐ 半衰期多久?据此该持有多久?
☐ 最优进场阈值是多少?(不是拍脑袋定 z>0.5)
☐ 1:1 对冲比率是最优的吗?
☐ 我的样本量够不够支撑这个结论?厚尾下要多少?
☐ 这个筛选器有没有在反向选择?
☐ 我的对手方为什么愿意和我成交?
```

**这七个问题,我们这四周每一个都撞到过,而且大多是靠犯错才发现的。**
补完课的标志不是读完书,是**下次能提前问出这些问题**。

## 六、最后一句

**这四周最值钱的东西不是金融知识,是那套怀疑自己的习惯:**

```
问系统本身,不问它的表象
解码要有外部可验证量
分布越偏,取样越危险
筛选目标必须和使用目标一致
有待定项就不出总数
```
